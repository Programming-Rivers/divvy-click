
# Release Notes: DivvyClick v0.4.0

We are thrilled to announce **DivvyClick v0.4.0**! 🚀

This release focuses on user experience improvements.

## ✨ Highlights

### Simplified screen tiling for quicker navigation

The screen is now divided into two pairs of tiles: top-bottom, and left-right.
This allows the user to choose the tiles with the muscle memory similar to using the arrow keys,
which is quicker for most users to do than learning to use a 9-key navigation system.

### Bug fixes

The DMG package now contains the universal binary for both Intel and Apple chips.
